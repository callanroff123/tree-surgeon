# Design System

Mood:
- Rural
- Documentary
- Warm
- Calm
- Authentic

Colours:
- Warm off-white
- Forest green
- Bark brown
- Clay accent

Typography:
- Humanist sans
- Editorial serif

Avoid:
- Gradients
- Huge rounded cards
- Generic hero sections
- Glassmorphism
- Template aesthetics

Photography:
Use real arborists and Australian landscapes wherever possible.
